ECE SUBJECT QUIZ - 2 PLAYER
============================

IMPORTANT:
Extract the ZIP first. Do NOT open index.html directly inside the ZIP preview.

After extraction, the folder must contain:
  index.html
  style.css
  script.js
  README.txt

Then double-click index.html.

Features:
- 30 ECE subject MCQs
- 2-player turn-based quiz
- 20-second timer
- Final score and percentage
- Responsive design

If you use VS Code:
1. Open the extracted folder.
2. Open index.html.
3. Use Live Server if available, or open index.html directly in the browser.
